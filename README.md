# College Project Website

## 📌 Overview
This project is a **College Website** built using **HTML and CSS**.  
It is designed to provide information about the college, courses, blogs, and contact details in a clean and user-friendly manner.

The project is structured with static web pages and a custom stylesheet to deliver a professional and responsive experience.

---

## ✨ Features
- **Homepage (`index.html`)** – Introduction to the college with navigation.  
- **About Page (`About.html`)** – Details about the institution.  
- **Courses Page (`Course.html`)** – Information on courses offered.  
- **Blog Page (`Blog.html`)** – A section for college news and updates.  
- **Contact Page (`contact.html`)** – Contact form and details.  
- **Custom Styles (`style.css`)** – Handles layout, design, and responsiveness.  
- **Images & Assets** – Includes background, logos, and college photos.  

---

## 🛠 Tech Stack
- **Frontend:** HTML5, CSS3  
- **Design:** Custom CSS for styling and layout  
- **Assets:** PNG images for background, logos, and photos
